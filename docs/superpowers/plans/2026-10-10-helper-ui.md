# Helper UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace wavvie's five-page dashboard with a one-window helper. One button checks the dates since the last check and saves the new songs to a dated private playlist.

**Architecture:**
- A new Qt-free `core/history.py` owns dates, history and playlist names.
- New pages (setup, sign-in, home, settings) and widgets (wave line, avatar, activity log) are built alongside the old UI.
- Task 7 then swaps `MainWindow` over in one step and deletes the old pages.
- The Spotify service, workers and paging stay as they are; there is one small change to the playlist description.

**Tech Stack:** Python 3.14, PySide6 6.11, spotipy 2.26, unittest, and Qt's offscreen platform for tests.

**Spec:** `docs/superpowers/specs/2026-10-10-helper-ui-design.md`

## Global Constraints

- Fonts: only Loubag (headings) and Agrandir (everything else). `tests/test_spotify_release_tool.py` greps `ui/**/*.py` for other font names and for negative `letter-spacing`.
- Palette: DEEP #0F2326, SURFACE #163338, RAISED #1D4047, LINE #2A5259, FOAM #EEF5F1, MIST #9DBAB6, SUN #F7C873, SUN_HOVER #FFD68F, ON_SUN #0F2326, CORAL #FF9A8B, SEA #8FE3B0.
- Copy: sentence case, no all-caps labels, and at most one SUN (primary) button visible per screen.
- Playlist name: "wavvie · New releases {a} – {b}" (dates like "10 Oct"; years only when they differ).
- The next check starts on the day the last complete check ran, so windows overlap by one day; songs saved earlier are skipped.
- Window: default 900×680, minimum 720×560, one content column of at most 600 px, and no horizontal scrolling.
- Preferences live in QSettings("wavvie", "SpotifyPlaylistCreator"). History lives under `check_history/<spotify user id>` as JSON.
- Tests never call Spotify or the network: use `tests/fake_spotify.py` and patch `core.workers.urllib.request.urlopen`.
- The CLI (`main.py run_cli`) keeps its behaviour.

## Review Focus

1. Damaged or older-format history JSON in QSettings must not stop the app; unreadable entries are ignored (Task 1 test).
2. A newest check dated after today (clock moved back) must suggest checking from today, not from a future date (Task 1 test).
3. Pressing Check twice, or triggering a check while one runs, must start only one scan (Task 7 test).
4. Signing in with a different Spotify account must not reuse the other account's history (Task 7 test).
5. Very long song, artist and playlist names must elide or wrap at the 720 px minimum width without horizontal scrolling (Task 8 test).

```python
"""Remembers which dates wavvie has checked and which songs each check saved."""
import json
from dataclasses import asdict, dataclass, field, fields
from datetime import date, timedelta
from typing import Iterable, List, Optional, Set

MAX_RECORDS = 20
MONTHS = ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec')


@dataclass
class CheckRecord:
    start: str                      # first day checked, ISO date
    end: str                        # day the check ran, ISO date
    ran_at: str
    songs: int = 0
    playlist_name: Optional[str] = None
    playlist_url: Optional[str] = None
    complete: bool = True
    artist_range: Optional[str] = None
    track_ids: List[str] = field(default_factory=list)

    @property
    def start_date(self) -> date:
        return date.fromisoformat(self.start)

    @property
    def end_date(self) -> date:
        return date.fromisoformat(self.end)


@dataclass(frozen=True)
class NextWindow:
    start: date
    kind: str  # 'first', 'ready', 'up_to_date' or 'finish'


class CheckHistory:
    def __init__(self, records: Iterable[CheckRecord] = ()):
        self.records: List[CheckRecord] = list(records)  # newest first

    @classmethod
    def from_json(cls, text: Optional[str]) -> 'CheckHistory':
        try:
            items = json.loads(text) if text else []
        except ValueError:
            return cls()
        known = {item.name for item in fields(CheckRecord)}
        records = []
        for item in items if isinstance(items, list) else []:
            try:
                record = CheckRecord(**{key: value for key, value in item.items() if key in known})
                date.fromisoformat(record.start)
                date.fromisoformat(record.end)
            except (AttributeError, TypeError, ValueError):
                continue
            records.append(record)
        return cls(records)

    def to_json(self) -> str:
        return json.dumps([asdict(record) for record in self.records])

    def next_window(self, today: date, look_back_days: int) -> NextWindow:
        if not self.records:
            return NextWindow(today - timedelta(days=look_back_days), 'first')
        unfinished = []
        for record in self.records:
            if record.complete:
                break
            unfinished.append(record)
        if unfinished:
            return NextWindow(min(min(record.start_date for record in unfinished), today), 'finish')
        start = min(self.records[0].end_date, today)
        return NextWindow(start, 'up_to_date' if start == today else 'ready')

    def saved_ids_since(self, start: date) -> Set[str]:
        return {track_id for record in self.records if record.end_date >= start
                for track_id in record.track_ids}

    def add(self, record: CheckRecord, today: date, look_back_days: int) -> None:
        self.records.insert(0, record)
        del self.records[MAX_RECORDS:]
        # Saved song IDs only matter where the next check can overlap them.
        keep_from = self.next_window(today, look_back_days).start
        for older in self.records:
            if older.end_date < keep_from:
                older.track_ids = []


def short_date(day: date, with_year: bool = False) -> str:
    text = f"{day.day} {MONTHS[day.month - 1]}"
    return f"{text} {day.year}" if with_year else text


def window_label(start: date, end: date) -> str:
    if start == end:
        return short_date(start)
    with_year = start.year != end.year
    return f"{short_date(start, with_year)} – {short_date(end, with_year)}"


def playlist_name(start: date, end: date) -> str:
    return f"wavvie · New releases {window_label(start, end)}"


def playlist_description(start: date, end: date) -> str:
    year = "" if start.year != end.year else f" {end.year}"
    return f"New releases from artists you follow, {window_label(start, end)}{year}. Made with wavvie."


def release_label(release_date: str) -> str:
    parts = (release_date or '').split('-')
    try:
        if len(parts) == 3:
            return f"{int(parts[2])} {MONTHS[int(parts[1]) - 1]}"
        if len(parts) == 2:
            return f"{MONTHS[int(parts[1]) - 1]} {parts[0]}"
    except (ValueError, IndexError):
        return release_date
    return release_date or ''
```

```python
"""Plain-language versions of errors from Spotify and the network."""
import re


def friendly_error(message, fallback=True):
    text = str(message or "")
    lowered = text.lower()
    if "max retries (" in lowered or re.search(r"\b429\b", text) or "rate limit" in lowered:
        return "Spotify is busy right now. Try again in a few minutes."
    if re.search(r"\b403\b", text):
        return ("Spotify refused the request. Check that your account is added to your app in the Spotify "
                "dashboard and that the app's owner has Premium.")
    if re.search(r"\b401\b", text) or "access token" in lowered or "invalid_grant" in lowered:
        return "Your Spotify sign-in has expired. Disconnect in Settings, then connect again."
    if any(word in lowered for word in ("connection", "timed out", "timeout", "resolve", "unreachable", "network")):
        return "wavvie couldn't reach Spotify. Check your internet connection and try again."
    if not fallback:
        return None
    return f"Spotify reported a problem: {text[:200]}" if text else "Something went wrong. Try again."
```

```python
"""Builders that give every page the same labels, buttons and column layout."""
from PySide6.QtCore import Qt
from PySide6.QtWidgets import QFrame, QHBoxLayout, QLabel, QPushButton, QScrollArea, QVBoxLayout, QWidget


def label(text="", role=None, wrap=True, selectable=False):
    widget = QLabel(text)
    widget.setTextFormat(Qt.PlainText)
    widget.setWordWrap(wrap)
    if role:
        widget.setProperty("role", role)
    if selectable:
        widget.setTextInteractionFlags(Qt.TextSelectableByMouse | Qt.TextSelectableByKeyboard)
    return widget


def button(text, role, name):
    widget = QPushButton(text)
    widget.setProperty("role", role)
    widget.setObjectName(name)
    widget.setCursor(Qt.PointingHandCursor)
    return widget


def rule():
    line = QFrame()
    line.setProperty("role", "rule")
    line.setFixedHeight(1)
    return line


def clear_layout(layout):
    while layout.count():
        item = layout.takeAt(0)
        if item.widget() is not None:
            item.widget().hide()
            item.widget().setParent(None)
            item.widget().deleteLater()
        elif item.layout() is not None:
            clear_layout(item.layout())


def scroll_column(owner, top=32, bottom=32):
    """Give owner a vertical scroll area holding one centred column up to 600 px wide."""
    outer = QVBoxLayout(owner)
    outer.setContentsMargins(0, 0, 0, 0)
    scroll = QScrollArea()
    scroll.setWidgetResizable(True)
    scroll.setFrameShape(QFrame.NoFrame)
    scroll.setHorizontalScrollBarPolicy(Qt.ScrollBarAlwaysOff)
    outer.addWidget(scroll)
    content = QWidget()
    scroll.setWidget(content)
    row = QHBoxLayout(content)
    row.setContentsMargins(24, top, 24, bottom)
    column = QWidget()
    column.setMaximumWidth(600)
    row.addStretch(1)
    row.addWidget(column, 100)
    row.addStretch(1)
    layout = QVBoxLayout(column)
    layout.setContentsMargins(0, 0, 0, 0)
    layout.setSpacing(12)
    return scroll, layout
```

```python
"""The one moving thing in wavvie: a line that ripples over the share of the check already done."""
import math

from PySide6.QtCore import QPointF, QTimer
from PySide6.QtGui import QColor, QPainter, QPainterPath, QPen
from PySide6.QtWidgets import QWidget

from ui.theme import Theme


class WaveLine(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setFixedHeight(28)
        self.progress = 0.0
        self.phase = 0.0
        self.active = False
        self.reduced_motion = False
        self.timer = QTimer(self)
        self.timer.timeout.connect(self.advance)

    def set_progress(self, fraction):
        self.progress = max(0.0, min(1.0, float(fraction)))
        self.update()

    def set_active(self, active):
        self.active = active
        self.sync_timer()
        self.update()

    def set_reduced_motion(self, enabled):
        self.reduced_motion = enabled
        self.sync_timer()
        self.update()

    def sync_timer(self):
        if self.active and self.isVisible() and not self.reduced_motion:
            self.timer.start(40)
        else:
            self.timer.stop()

    def showEvent(self, event):
        super().showEvent(event)
        self.sync_timer()

    def hideEvent(self, event):
        self.timer.stop()
        super().hideEvent(event)

    def advance(self):
        self.phase = (self.phase + 0.35) % (2 * math.pi)
        self.update()

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)
        middle = self.height() / 2
        done = self.width() * max(self.progress, 0.04 if self.active else 0.0)
        painter.setPen(QPen(QColor(Theme.LINE), 2))
        painter.drawLine(QPointF(done, middle), QPointF(self.width(), middle))
        if done <= 0:
            return
        path = QPainterPath()
        path.moveTo(0, middle + 5 * math.sin(-self.phase))
        x = 0.0
        while x < done:
            x = min(done, x + 2.0)
            path.lineTo(x, middle + 5 * math.sin(x / 14.0 - self.phase))
        painter.setPen(QPen(QColor(Theme.SUN), 2.5))
        painter.drawPath(path)
```

```python
        super().__init__(parent)
        self.setFixedSize(size, size)
        self.image: Optional[QImage] = None
        self.initial = ""

    def set_user(self, name, image=None):
        self.initial = (name or "").strip()[:1].upper()
        self.image = image
        self.setToolTip(name or "")
        self.setAccessibleName(f"Signed in as {name}" if name else "Not signed in")
        self.update()

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)
        clip = QPainterPath()
        clip.addEllipse(QRectF(self.rect()))
        painter.setClipPath(clip)
        if self.image is not None and not self.image.isNull():
            scaled = self.image.scaled(self.size(), Qt.KeepAspectRatioByExpanding, Qt.SmoothTransformation)
            painter.drawImage((self.width() - scaled.width()) // 2, (self.height() - scaled.height()) // 2, scaled)
            return
        painter.fillRect(self.rect(), QColor(Theme.RAISED))
        font = painter.font()
        font.setFamily(Theme.FONT_BODY)
        font.setPixelSize(max(10, int(self.height() * 0.45)))
        font.setBold(True)
        painter.setFont(font)
        painter.setPen(QColor(Theme.FOAM))
```

```python
import logging

from PySide6.QtCore import QObject, QTimer, Signal, Slot
from PySide6.QtGui import QGuiApplication

class SignallingLogHandler(logging.Handler, QObject):
    log_emitted = Signal(str, int)

    def __init__(self):
        logging.Handler.__init__(self)
        QObject.__init__(self)
        self.setFormatter(logging.Formatter('%(asctime)s - %(levelname)s - %(message)s', datefmt='%H:%M:%S'))

    def emit(self, record):
        self.log_emitted.emit(self.format(record), record.levelno)


class ActivityLog(QObject):
    changed = Signal()

    def __init__(self, parent=None, limit=2000):
        super().__init__(parent)
        self.lines = []
        self.limit = limit
        self.handler = SignallingLogHandler()
        self.handler.log_emitted.connect(self.append)
        logging.getLogger().addHandler(self.handler)

    @Slot(str, int)
    def append(self, message, level):
        self.lines.append(message)
        del self.lines[:-self.limit]
        self.changed.emit()

    def text(self):
        return "\n".join(self.lines)

    def detach(self):
        logging.getLogger().removeHandler(self.handler)


class ActivityLogDialog(QDialog):
```

```python
        worker.signals.finished.connect(self.on_auth_success)
        worker.signals.error.connect(self.on_auth_error)
        self.launch_worker(worker)

    def cancel_authentication(self):
        if self.operation != "auth":
            return
        self.sign_in_cancelled = True
        self.service.cancel_authentication()

    def on_auth_success(self, user):

        if self.closing:
            return
        name = user.get('display_name') or 'Spotify user'
        self.avatar.set_user(name)
        images = user.get('images') or []
        if images:
            self.download_image(images[0]['url'], lambda image: self.avatar.set_user(name, image), 64)
        self.settings_page.set_account(name)
        stored = QSettings("wavvie", "SpotifyPlaylistCreator").value(self.history_key(), "", type=str)
        self.history = CheckHistory.from_json(stored)
        self.show_page(self.home_page)
        self.load_followed_artists()

    def on_auth_error(self, message):
        self.set_operation(None)
        if self.closing:
            return
        error = None
        if not self.sign_in_cancelled:
            error = friendly_error(message, fallback=False) or (
                f"Couldn't connect to Spotify. Check that your app's redirect URI is "
                f"{self.service.redirect_uri}, then try again.")
        self.sign_in_page.show_idle(error)
        self.show_page(self.sign_in_page)

    def history_key(self):
        return f"check_history/{(self.service.user_data or {}).get('id', 'unknown')}"

    def load_followed_artists(self, refresh=False):
        if not self.can_start_operation():
            return
        self.service.cancelled = False
        self.set_operation("artists")
        self.home_page.show_loading_artists()
        worker = LoadArtistsWorker(self.service, refresh)
        worker.signals.finished.connect(self.on_artists_loaded)
        worker.signals.error.connect(self.on_artists_error)
        self.launch_worker(worker)

    def on_artists_loaded(self, artists):
        self.set_operation(None)
        self.followed_count = len(artists)
        self.settings_page.set_artist_count(self.followed_count)
        if not self.closing:
            self.show_home_ready()

    def on_artists_error(self, message):
        self.set_operation(None)
        if not self.closing:
            self.home_page.show_artists_failed(friendly_error(message))

    def refresh_artists_from_settings(self):
        self.close_settings()
        self.load_followed_artists(refresh=True)

    def show_home_ready(self):
        self.pending = None
        if not self.followed_count:
            self.home_page.show_no_artists()
            return
        look_back = read_preferences().look_back_days
        window = self.history.next_window(date.today(), look_back)
        self.home_page.show_ready(window, self.followed_count, look_back, self.history.records)

    def start_check(self, start=None):
        if not self.can_start_operation():
            return
        preferences = read_preferences()
        today = date.today()
        start = min(start or self.history.next_window(today, preferences.look_back_days).start, today)
        first, last = preferences.artist_range or (1, 9999)
        self.check_start, self.check_end, self.check_range = start, today, preferences.artist_range
        self.scan_warnings = []
        self.check_config = ScanConfiguration(
            start_index=first, end_index=last, cutoff_date_str=start.isoformat(),
            playlist_name=playlist_name(start, today), playlist_description=playlist_description(start, today),
            worker_count=preferences.workers, export_json=preferences.export_json, create_playlist_auto=True)
        self.set_operation("scan")
        self.home_page.show_checking(max(0, min(last, self.followed_count) - first + 1), start)
        worker = ScanWorker(self.service, self.check_config)
        worker.signals.progress.connect(self.on_check_progress)
        worker.signals.rate_limit.connect(self.home_page.show_rate_limited)
        worker.signals.warning.connect(self.scan_warnings.append)
        worker.signals.finished.connect(self.on_check_finished)
        worker.signals.error.connect(self.on_check_error)
        self.launch_worker(worker)

    def on_check_progress(self, update):
        if self.operation == "scan":
            progress = update[1]
            self.home_page.update_progress(progress.processed_artists, progress.total_artists, progress.tracks_found)

    def stop_check(self):
        if self.operation != "scan":
            return
        self.set_operation("cancelling")
        self.service.cancel_scan()
        self.home_page.show_stopping()

    def on_check_error(self, message):
        cancelled = self.operation == "cancelling" or self.service.cancelled
        self.set_operation(None)
        if self.closing:
            return
        if cancelled:
            self.home_page.show_stopped()
        else:
            self.home_page.show_failed(friendly_error(message))

    def on_check_finished(self, result):
        self.set_operation(None)
        if self.closing:
            return
        skip = self.history.saved_ids_since(self.check_start)
        tracks = [track for track in result.tracks if track.track_id not in skip]
        notes = []
        if self.scan_warnings:
            notes.append(SOME_ARTISTS_FAILED)
        if self.check_range:
            notes.append(f"Only artists {self.check_range[0]}–{self.check_range[1]} were checked, "
                         f"so your next check will look at these dates again.")
        complete = not self.scan_warnings and not self.check_range
        if not tracks:
            self.record_check(songs=0, complete=complete)
            self.home_page.show_nothing_new(self.check_start, notes)
            return
        json_file = None
        if self.check_config.export_json:
            json_file = self.service.dump_tracklist_to_json(tracks, result.start_index, result.end_index)
        self.pending = PendingSave(tracks, self.check_config, result.start_index, result.end_index,
                                   result.followed_artists, complete, notes, json_file)
        self.save_pending()

    def save_pending(self):
        if self.pending is None or not self.can_start_operation():
            return
        pending = self.pending
        self.set_operation("playlist")
        self.service.cancelled = False
        self.home_page.show_saving(len(pending.tracks))
        worker = PlaylistWorker(self.service, pending.tracks, pending.config, pending.start_index,
                                pending.end_index, pending.followed_artists)
        worker.signals.finished.connect(self.on_playlist_saved)
        worker.signals.error.connect(self.on_playlist_failed)
        self.launch_worker(worker)

    def on_playlist_saved(self, result):
        self.set_operation(None)
        pending, self.pending = self.pending, None
        if pending is None:
            return
        saved = list(dict.fromkeys(track.track_id for track in pending.tracks if track.track_id))
        added = saved[:result.tracks_added]
        partial = bool(result.error) or len(added) < len(saved)
        notes = pending.notes + ([PARTLY_SAVED] if partial else [])
        self.record_check(songs=len(added), complete=pending.complete and not partial, playlist=result,
                          track_ids=added)
        if not self.closing:
            self.home_page.show_done(result.playlist_name, result.playlist_url, pending.tracks, notes,
                                     pending.json_file, added=len(added) if partial else None)

    def on_playlist_failed(self, message):
        self.set_operation(None)
        if self.pending is not None and not self.closing:
            self.home_page.show_not_saved(len(self.pending.tracks), friendly_error(message))

    def record_check(self, songs, complete, playlist=None, track_ids=()):
        record = CheckRecord(
            start=self.check_start.isoformat(), end=self.check_end.isoformat(),
            ran_at=datetime.now().isoformat(timespec='seconds'), songs=songs,
            playlist_name=getattr(playlist, 'playlist_name', None),
            playlist_url=getattr(playlist, 'playlist_url', None), complete=complete,
            artist_range=f"{self.check_range[0]}–{self.check_range[1]}" if self.check_range else None,
            track_ids=list(track_ids))
        self.history.add(record, date.today(), read_preferences().look_back_days)
        QSettings("wavvie", "SpotifyPlaylistCreator").setValue(self.history_key(), self.history.to_json())

    def download_image(self, url, callback, target_size=200):
        if not url:
            return
        key = (url, target_size, self.account_generation)
        if key in self.artwork_cache:
            callback(self.artwork_cache[key])
            return
        if key in self.image_requests:
            self.image_requests[key].append(callback)
            return
        self.image_requests[key] = [callback]
        worker = ImageLoadWorker(url, target_size)

        def on_success(image):
            callbacks = self.image_requests.pop(key, [])
            if key[2] != self.account_generation:
                return
            if len(self.artwork_cache) >= 256:
                self.artwork_cache.pop(next(iter(self.artwork_cache)))
            self.artwork_cache[key] = image
            for apply_image in callbacks:
                apply_image(image)

        worker.signals.finished.connect(on_success)
        worker.signals.error.connect(lambda error: self.image_requests.pop(key, None))
        self.launch_worker(worker)

    def load_artwork(self, url):
        self.download_image(url, lambda image: self.home_page.set_artwork(url, image), 80)

    def open_settings(self):
        if self.service.user_data:
            self.show_page(self.settings_page)

    def close_settings(self):
        if self.stack.currentWidget() is self.settings_page:
            self.show_page(self.home_page)

    def apply_preferences(self):
        self.home_page.set_reduced_motion(read_preferences().reduced_motion)

    def on_settings_changed(self):
        self.apply_preferences()
        if self.home_page.state == 'ready' and not self.operation:
            self.show_home_ready()

    def open_activity_log(self):
        if self.log_dialog is None:
            self.log_dialog = ActivityLogDialog(self.activity_log, self)
        self.log_dialog.show()
        self.log_dialog.raise_()
        self.log_dialog.activateWindow()

    def disconnect_account(self):
        if not self.can_start_operation():
            return
        self.account_generation += 1
        self.service.disconnect()
        self.artwork_cache.clear()
        self.followed_count = 0
        self.history = CheckHistory()
        self.pending = None
        self.avatar.set_user("")
        self.settings_page.set_account("")
        self.sign_in_page.show_idle()
        self.show_page(self.sign_in_page)

    def closeEvent(self, event):
        if self.thread_pool.activeThreadCount():
            event.ignore()
            if not self.closing:
                self.closing = True
                if self.operation == "scan":
                    self.stop_check()
                elif self.operation == "auth":
                    self.cancel_authentication()
                else:
                    self.service.cancel_scan()
                self.set_operation(self.operation)
                self.setWindowTitle("wavvie (finishing up…)")
                self.close_timer = QTimer(self)
                self.close_timer.timeout.connect(self.finish_close)
                self.close_timer.start(200)
            return
        self.activity_log.detach()
        if self.log_dialog is not None:
            self.log_dialog.close()
        event.accept()

    def finish_close(self):
        if self.operation == "auth":
            # Close may have been requested before spotipy started waiting for the browser.
            self.service.cancel_authentication()
        if not self.thread_pool.activeThreadCount():
            self.close_timer.stop()
            self.close()
```
